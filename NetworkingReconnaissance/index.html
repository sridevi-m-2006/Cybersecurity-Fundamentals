What is Networking?

Computer networking is the connection of two or more devices to share information and resources. Networks allow computers to communicate using protocols, IP addresses and ports.

Fundamental Networking Concepts

IP Address

An IP address is a unique network address used to identify a device and communicate over a network.

Example: 192.168.1.10

DNS

Domain Name System (DNS) translates domain names into IP addresses so computers can locate servers.

Example: example.com

Ports

Ports are logical communication endpoints used by applications and network services.

Example: Port 443

Protocols

Protocols are rules that allow devices to communicate and exchange information.

Example: TCP, UDP, HTTP

Common Network Ports and Protocols

Port Protocol Purpose
20 / 21 FTP File transfer
22 SSH Secure remote access
25 SMTP Sending email
53 DNS Domain name resolution
80 HTTP Web communication
443 HTTPS Secure web communication

Basic Networking Commands

These commands help you understand network configuration and connectivity. Run them on your own computer.

1. ipconfig

Displays network configuration on Windows.

ipconfig

2. ping

Checks basic connectivity to a destination.

ping -n 4 example.com

3. nslookup

Finds DNS information for a domain name.

nslookup example.com

4. tracert

Shows the network route taken by packets on Windows.

tracert example.com

5. whois

Looks up publicly available domain registration information. Availability depends on your system and the WHOIS service used.

whois example.com

6. ipconfig /all

Displays detailed network adapter information.

ipconfig /all

Note: These are example commands. Some commands may need additional tools. Use them only for learning and authorized network checks.

What is Reconnaissance?

Reconnaissance is the information-gathering stage of cybersecurity assessment. It helps security professionals understand a target before an authorized security test.

Passive Reconnaissance

Collecting publicly available information without directly interacting with the target system.

Example: Public DNS records and published website information.

Active Reconnaissance

Interacting directly with a system to collect technical information. It requires permission.

Example: An approved network connectivity or service check.

Basic Reconnaissance Workflow

Identify an authorized domain
↓
Gather public information
↓
Understand DNS and network details
↓
Document findings

Safety and Ethical Guidelines

Get Permission

Test only systems that you own or have explicit permission to assess.

Respect Privacy

Use publicly available information responsibly. Do not collect private information without permission.

Document Findings

Record your observations clearly and report security concerns responsibly.
